# سكينة (Sakina) — القرآن الكريم والأذكار بلا إنترنت

تطبيق مجاني ومفتوح المصدر لقراءة القرآن الكريم وحفظه ومراجعته، وقراءة الأذكار اليومية مع سبحة إلكترونية — يعمل بالكامل بدون إنترنت.

- **الموقع الرسمي**: [https://sakina-lyart.vercel.app/](https://sakina-lyart.vercel.app/)
- **المصدر البرمجي**: [https://github.com/ghassanelgendy/sakina](https://github.com/ghassanelgendy/sakina)

## الأقسام والميزات
- **المصحف الشريف**: تلاوة وتفسير الميسر مع تلاوات صوتية متعددة.
- **الأذكار**: أذكار الصباح والمساء، أذكار النوم والصلاة مع عداد إلكتروني ووضع ملء الشاشة.
- **أدوات الحفظ**: خطة الختمة ونظام التكرار المتباعد لتثبيت الحفظ.
- **دون إنترنت**: يعمل كتطبيق PWA دون الحاجة لأي اتصال بالشبكة بعد أول تشغيل.
